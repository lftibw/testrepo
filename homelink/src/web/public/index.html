SmartThings

Samsung SmartThings account — lights, switches, plugs & ACs.

How do I set this up? (connects permanently, no daily re-token)
  1. Install the SmartThings CLI: npm i -g @smartthings/cli (or download it from GitHub releases).
  2. Run smartthings apps:create → choose OAuth-In SmartApp.
  3. Scopes: enter r:devices:*, x:devices:*, r:locations:*.
  4. Redirect URI: paste … exactly.
  5. The CLI prints an OAuth Client ID and Client Secret — enter them above, then click Authorize and approve in the SmartThings page that opens.

Why: this uses a refresh token that HomeLink renews automatically, so the connection never expires (unlike a 24-hour personal token).

How do I get a token?
  1. Go to account.smartthings.com/tokens and sign in.
  2. Click Generate new token, name it “HomeLink”.
  3. Check the Devices scopes (list, see, control).
  4. Copy the token and paste it above. ⚠️ Tokens created after Dec 2024 expire in 24h — use the Auto-refresh tab to stay connected permanently.

Wipro / Tuya

Wipro smart lights & other Tuya devices.

Scan with the Smart Life app (Me → ⊕ scanner icon) and approve. Waiting…

How does this work? (no developer account needed)
  1. Install the Smart Life app and add your Wipro bulbs there (they're Tuya devices — flick the light off/on 3× to reset, then Add Device). Note: a bulb lives in one app at a time, so it moves out of Wipro Next.
  2. In Smart Life: Me → Settings ⚙ → Account and Security → User Code — enter that code above.
  3. Tap the button, scan the QR with Smart Life's scanner, approve — done. No Tuya console, no data centers.

How do I link my Wipro account?
  1. Create a free account at iot.tuya.com → Cloud → Create Cloud Project. Pick the data center your app account lives in — for Wipro Next that is usually Central Europe (the app predates Tuya's Sep 2020 cutoff, so Indian accounts were homed in Frankfurt). If linking fails there, try India.
  2. In the project, subscribe to the trial of IoT Core and Authorization Token Management APIs.
  3. Open Devices → Link App Account → Add App Account and scan the QR with the Wipro Next Smart Home (or Smart Life) app: Me → ⚙ / scanner icon.
  4. Copy the project’s Access ID and Access Secret (Overview tab) here.
